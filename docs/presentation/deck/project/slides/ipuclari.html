Sınıfta kullanım

Kaygıyı artırmadan söz vermek

Amaç öğrenciyi yakalamak değil, herkese söz hakkı tanımak.

Önce soru, sonra isim

Düşünme süresi

Önce ikili prova

Çabayı ödüllendirin

(~60 sn) Rastgele söz vermek, özellikle dil dersinde, yanlış kullanılırsa kaygıyı artırabilir. Bunu önlemek için dört öneri: Birincisi, önce soruyu sorun, sonra seçin; böylece herkes cevabı düşünür. İkincisi, düşünme süresi verin. Üçüncüsü, seçimden önce öğrencilerin cevabı sıra arkadaşıyla prova etmesine izin verin; seçilen öğrenci yalnız değil, hazırlanmış oluyor. Dördüncüsü, artı puanı çabaya da verin; takılan öğrenciye ipucu verip geri dönün. Amaç öğrenciyi yakalamak değil, herkese söz hakkı tanımak.
